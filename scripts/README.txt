Jack Universe — запуск на Linux (Ubuntu, x64). Node.js ставить не нужно.

1. Распаковать архив и зайти в папку:
     tar -xzf jack-universe-linux.tar.gz
     cd jack-universe

2. Если файл не запускается — дать права на запуск (один раз):
     chmod +x jack-universe

3. Запустить:
     ./jack-universe
   В консоли появятся адреса. Браузер на этом компьютере откроется сам
   (если нет — открыть http://localhost:3000). Это большой экран.
   Другой порт: PORT=8080 ./jack-universe

4. Телефоны должны быть в той же Wi-Fi сети. Они заходят по адресу
   http://<IP-компьютера>:3000 из консоли (или по QR-коду на экране).

5. Если телефоны не открывают страницу — разрешить порт в фаерволе:
     sudo ufw allow 3000/tcp

6. Звук: браузер не играет звук, пока по странице не кликнули.
   Кликните один раз по экрану игры.

7. Что можно менять (рядом с программой, без пересборки,
   после изменения перезапустить ./jack-universe):
     вопросы.xlsx          — вопросы: A — вопрос, B–E — варианты, F — файл озвучки
     public/voice/...      — озвучка ведущего (mp3)
     public/img/...        — картинки

Остановить: Ctrl+C в консоли.
